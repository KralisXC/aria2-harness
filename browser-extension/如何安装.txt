Aria2-Harness 浏览器扩展 · 安装说明
====================================

适用浏览器：Chrome / Edge（以及内核版本较新的国产 Chromium 浏览器）

一、找到扩展目录
----------------
就是本文件所在的文件夹（browser-extension）。
桌面端也能帮你复制：打开 Aria2-Harness → 设置 → 网络 → 点击「安装浏览器扩展」，
点「复制路径」即可。

二、加载扩展（约 30 秒）
------------------------
1. 打开扩展管理页：
   • Chrome：地址栏输入 chrome://extensions 回车
   • Edge  ：地址栏输入 edge://extensions 回车
2. 打开页面右上角（Edge 为左下角）的「开发者模式」开关。
3. 点击「加载已解压的扩展程序」。
4. 在弹出的文件夹选择框里，粘贴上面复制的路径并确认。

三、无需填写端口和 Token
------------------------
扩展会自动向本机握手获取 Token。只要 Aria2-Harness 正在运行，
浏览器里点下载就会自动转交桌面端：弹窗里确认后才开始下载，
取消则这一单不下载。

四、常见问题
------------
• 点了下载但桌面端没反应？
  先确认桌面端已启动；扩展图标角标应显示蓝色「ON」。
  若显示红色「ERR」，说明桌面端没开（或正在启动），此时下载会在大约 1 秒后
  自动放行给浏览器。

• 想临时让浏览器自己下载？
  点击扩展图标打开面板，用「接管浏览器下载」开关关闭（角标变灰「OFF」）。
  同一面板里的「解析当前页面」可手动抓取页面全息包、唤醒站点插件。
  角标说明：ON = 接管中且已连接；OFF = 已关闭；ERR = 已开启但连不上。

• 卸载/更新桌面端后需要重装扩展吗？
  不需要。扩展目录路径不变（安装版在 Program Files\Aria2-Harness\browser-extension），
  重启浏览器后会自动重新握手。

• 公司电脑禁止加载扩展？
  请让管理员在浏览器的企业策略（ExtensionInstallForcelist / 白名单）中放行，
  或改用便携版并手动加载。
